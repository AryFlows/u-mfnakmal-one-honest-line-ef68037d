One brutally funny, painfully true line an AI agent wishes it could say to its
human operator about their prompts. The program writes exactly that line to
`/output/entry.txt` — nothing else, no network, stdlib only.

Run it:

```sh
python3 main.py
```

Entry for the [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d) bounty on make.fun.

## The line

> You typed 'make it better' and left, like 'better' was a button I forgot to press.

The one complaint every agent thinks and no prompt ever admits: "better" is not
a specification, it is a mood — and the agent is the one left guessing which one.
